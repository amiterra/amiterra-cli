= Platform Contracts
:description: Everything the Amiterra platform guarantees — names, paths, versions, and forms you may rely on.

A *contract* is any name, path, version, or output form that crosses the
boundary between the platform and your applications. Contracts are
guarantees: `stable` values change only as a release event (changelog +
deprecation window), never silently. Everything outside this registry
carries no guarantees.

The registry is the single source of truth; a contract test keeps this page
in sync with the binary (`ami contracts`), so a constant cannot drift from
its documentation.

== Discoverability

* `ami contracts [--json] [--section <name>]` — the full registry, offline.
* `ami versions [--json]` — pinned component versions (the exact values the
  installer deploys; plan compatibility against these, not against "latest").
* `ami doctor` — verifies contract invariants against the live host/cluster
  (StorageClass, data root, Cilium manifest invariants, foreign PVC classes).

== Behavior & honesty

[cols="1,3,1,2", options="header"]
|===
| ID | Value | Stability | Source

| `behavior-enforcement-honesty`
| `rateLimitRps`, `clientAuth: mtls`, `trustedProxySource` XFF — contract, not enforced; CORS emits only for a single origin
| stable
| `amispec-compile/exposure`
|===

These fields are *declared* semantics: the platform marks them
"DECLARED, NOT ENFORCED" instead of pretending. Do not rely on them for
protection until enforcement ships.

== CLI surface

[cols="1,3,1,2", options="header"]
|===
| ID | Value | Stability | Source

| `cli-json-forms`
| `ami {status,doctor,contracts,versions,network status,storage} --json`
| experimental
| `cli.rs`
|===

Current JSON shapes (experimental — fields may change with a changelog note):

* `ami contracts --json` → `{ "contracts": [ { "id", "title", "value", "stability", "since", "source", ... } ] }`
* `ami versions --json` → `{ "cli", "k3s", "ciliumChart", "flux", "certManager", "amispecSchema" }`
* `ami doctor --json` → report including `contract_checks` and `network_drift`
* `ami network status --json` → `{ "drift", "snapshot_mismatch", "egress_ip", "cloud_provider" }`

== Stability policy

[cols="1,2,2", options="header"]
|===
| Stability | Guarantee | How it changes

| `stable`
| Safe to rely on in production
| Release version + changelog + deprecation window (≥1 minor) + migration note; renames keep the old name alive for the window

| `experimental`
| Usable, but expect changes
| Changelog entry; always marked in `ami contracts`

| `internal`
| Not an interface (debugging aid)
| May change at any moment
|===
